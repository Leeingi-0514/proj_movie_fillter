넷플릭스 구간 필터

넷플릭스 영상을 확인하는 중…

1. 구간 준비

기존 클립 7개의 시간은 본편 시간이 아닙니다. 아래에서 클립 시작 위치를 맞춰 주세요.

2. 시간 맞추기

실제 적용 시간 = JSON 시간 + 보정 값. 본편 기준 JSON이면 0을 사용하세요. 예: 클립 시작이 본편 20분이면 1200.

3. 적용 방식

스킵은 검은 화면에서 요약을 약 3초간 보여준 뒤 구간 끝으로 이동합니다.

블러가 보이지 않으면 ‘화면 완전히 가리기’를 선택하세요. 필터를 끄면 모든 구간 처리가 중지됩니다.

본편 재생 중에 저장하세요. 이 주소의 작품·에피소드에만 연결됩니다. 다른 회차는 따로 등록합니다.
