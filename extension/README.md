# MovieGuard for Netflix

넷플릭스 웹 재생 화면에서 작품별 JSON의 시간 구간에 맞춰 블러·음소거·스킵을 적용하는 Chrome Manifest V3 확장 프로그램입니다. 별도 서버, API 키, 유료 호스팅은 필요하지 않습니다. 넷플릭스 이용은 본인의 계정으로 합니다.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 선택합니다. ZIP을 받았다면 먼저 압축을 풀어 `manifest.json`이 있는 폴더를 선택합니다.
4. 기존 MovieGuard 확장이 설치되어 있다면 이전 확장을 끄거나 해당 확장의 새로고침 버튼으로 업데이트해 중복 실행을 피합니다.
5. 이미 열어 둔 넷플릭스 탭은 새로고침합니다. 크롬 도구 모음의 확장 프로그램 목록에서 MovieGuard를 고정하면 편리합니다.

공식 설치 안내: https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 첫 필터 적용

1. 넷플릭스에서 원하는 작품·회차의 **본편**을 재생합니다. 자동 미리보기나 광고가 아닌 본편에서 설정합니다.
2. MovieGuard 아이콘을 누릅니다. 현재 작품 ID와 재생 시간이 표시되는지 확인합니다.
3. **기존 클립 구간**에서 작품을 선택하거나 **JSON 불러오기**로 기존 `assets/segments/` 파일을 선택합니다. 기존 7개 클립의 구간만 함께 제공하며 영상 파일은 포함하지 않습니다. 제목 선택만으로 같은 넷플릭스 작품을 찾거나 자동 연결하지 않습니다.
4. **시간 보정**을 맞춥니다. 본편 기준 JSON이면 `0`입니다. 로컬 클립 기준 JSON이라면 본편을 클립의 시작 장면에 맞춰 일시 정지하고 **현재 재생 위치를 클립 시작(0초)으로**를 누릅니다.
5. 적용 방식을 선택합니다. **JSON대로**는 구간별 `type`을 사용하며 **블러 / 음소거 / 블러 + 음소거 / 스킵**은 모든 구간을 선택한 방식으로 처리합니다.
6. **현재 작품에 저장·적용**을 누릅니다. 팝업을 닫아도 동작합니다. 같은 작품 주소로 다시 들어오면 저장한 구간을 불러옵니다. 변경 후에도 이 버튼을 눌러야 반영됩니다.

실제 적용 시간은 `JSON의 start/end + 시간 보정(초)`입니다. 예를 들어 클립 시작이 본편 20분이면 보정은 `1200`, JSON의 `8.1~10.3` 구간은 본편 `20:08.1~20:10.3`에 적용됩니다. 양수·음수 보정과 0.1초 입력을 지원합니다. 하나의 보정 값은 클립 전체가 같은 길이로 이어질 때만 맞습니다. 편집본·여러 클립을 합친 JSON은 본편 기준으로 각 구간을 다시 작성해야 합니다.

## 작동 방식

**스킵 요약**: 해당 구간에 들어오면 영상을 일시 정지하고 검은 화면에 `summary`를 약 3초간 표시합니다. 이어서 구간 끝으로 이동하며, 원래 재생 중이었다면 이어 재생하고 원래 멈춰 있었다면 정지 상태를 유지합니다. 요약 중에는 영상 자막 대신 요약만 표시합니다. 겹치거나 맞닿는 구간은 요약을 시간 순서대로 합치고 같은 문장을 중복 표시하지 않습니다.

팝업의 각 구간에서 **스킵 요약**을 편집한 후 저장·적용할 수 있습니다. 기존에 연결한 JSON을 수정한 경우 다시 불러와 저장해야 합니다. `summary`가 없는 옛 파일은 기본 안내문을 보여주며, 자동 내용 분석은 하지 않습니다. 필터 끄기·연결 해제·다른 작품 이동·구간 밖 탐색 시 남은 요약 타이머를 취소합니다. 스킵 이동이 실패하면 검은 화면과 안내문을 유지하므로 재생 위치를 옮기거나 필터를 꺼 주세요.

- `https://netflix.com` 및 그 하위 도메인의 `/watch/숫자ID` 화면에서만 필터를 실행합니다. 회차마다 ID가 다르므로 각각 연결합니다. 다음 화·홈 이동 시 이전 작품의 효과를 해제합니다.
- `start`를 포함하고 `end`는 제외합니다. 구간이 겹치면 블러와 음소거를 함께 적용하며, 이어지는 스킵 구간은 마지막 끝까지 이동합니다.
- 구간 종료, 필터 끄기, 연결 해제, 영상 교체 시 확장이 적용한 음소거와 화면 효과를 해제합니다. 사용자가 원래 켠 음소거는 유지합니다.
- 넷플릭스에서 직접 음소거를 해제하거나 팝업의 **지금 소리 켜기**를 누르면 해당 연속 음소거 구간이 끝날 때까지 소리를 유지합니다. 다음 구간에서는 다시 자동 음소거합니다.
- 자막을 켜 두면 블러·화면 가리기 위에 자막을 선명하게 표시합니다. 넷플릭스 화면의 자막과 HTML5 텍스트 트랙을 지원하며, 언어 변경·자막 끄기를 따릅니다. 구간 종료·필터 끄기·다음 화 이동 시 원래 자막 표시로 복원합니다. 영상 자체에 글자가 합쳐진 자막(하드 자막)은 분리할 수 없어 영상과 함께 흐려집니다.
- 블러가 보이지 않는 보호 영상 환경에서는 **화면 처리 → 화면 완전히 가리기**로 바꾼 후 저장합니다. 이는 블러 대상 장면을 불투명한 검은 화면으로 덮습니다. 일반 페이지 전체 화면에 대응하며, 별도 PIP 창·다른 기기로 전송한 화면에는 효과가 전달되지 않습니다.
- 저장 당시와 영상 길이가 3초 넘게 달라지면 잘못된 타임라인 적용을 피하기 위해 대기합니다. 본편에서 구간과 시간을 확인한 뒤 다시 저장합니다. 광고나 서비스 편집 변경으로 시간 기준이 달라지면 재조정이 필요합니다.
- 영상 분석이나 민감 장면 자동 검출은 수행하지 않습니다. 기본 7개 구간은 로컬 클립용 예시이며 **넷플릭스 본편 전체를 보호하는 데이터가 아닙니다**.

## JSON 형식

기존 `{ "title": "…", "segments": [...] }` 파일을 그대로 읽습니다. 소수 초 또는 `분:초.소수`, `시:분:초.소수`를 사용할 수 있습니다.

```json
{
  "title": "작품 이름 / 회차",
  "segments": [
    { "id": "scene-001", "start": 8.1, "end": 10.3, "type": "both", "reason": "필터 구간", "summary": "이 장면에서 일어나는 일을 짧게 적습니다." }
  ]
}
```

`type`은 `blur`, `mute`, `both`, `skip`입니다. 같은 파일의 `id`는 중복될 수 없으며 생략하면 자동 생성합니다. 음수 구간, 종료가 시작보다 빠른 구간, 잘못된 필터 타입은 오류로 안내합니다. `version`과 `category`는 사용하지 않습니다.

내보낸 JSON에는 `netflixId`, `offset`, `mode`, `mask`를 추가해 시간 보정과 적용 방식을 함께 보관합니다. `netflixId`가 있으면 다른 작품에 저장하지 못하도록 확인합니다. 확장 프로그램 관리에 필요한 `manifest.json`의 `version`은 Chrome이 요구하는 별도 값입니다.

## 저장·권한

설정은 `chrome.storage.local`의 `movieGuardNetflix`에 작품 ID별로 저장됩니다. 서버 전송이나 계정·쿠키 접근은 하지 않습니다. 권한은 로컬 설정 저장(`storage`), 팝업에서 현재 탭 확인(`activeTab`), 넷플릭스 페이지의 콘텐츠 스크립트 실행뿐입니다. 넷플릭스의 일반 영상 요소에 화면 스타일, `muted`, `currentTime`을 적용하며 DRM을 해제하거나 스트림을 가져오지 않습니다.

## 확인한 범위와 테스트

엔진 자동 검사와 로컬 HTML5 영상의 브라우저 통합 검사를 수행했습니다. **실제 로그인한 넷플릭스의 보호 영상 재생은 이 환경에서 검증하지 않았습니다.** 넷플릭스 플레이어 변경, 광고형 요금제의 시간 기준, 기기별 보호 영상 처리에 따라 추가 조정이 필요할 수 있습니다. 0.1초 단위의 JSON 입력을 지원하지만 브라우저 스케줄링·디코딩 때문에 프레임 단위 정확도를 보장하지 않습니다.

설치 후 짧은 구간 하나를 등록해 블러, 음소거, 스킵을 각각 확인하고, 구간 종료·직접 음소거 해제·다음 화 이동도 확인해 주세요. 블러가 실패하면 화면 가리기로 확인합니다. 모든 방식이 작동하지 않으면 넷플릭스 탭을 새로고침하고 본편의 작품 ID와 시간 보정을 확인합니다.

프로젝트 루트에서:

```sh
npm test
python3 tests/serve_extension_qa.py
```

두 번째 명령 실행 후 `http://127.0.0.1:8018/watch/101`에서 **Run integration tests**를 누릅니다. 이 페이지는 로컬 샘플 영상과 Chrome API 대역을 사용하며, 실제 확장 설치 또는 넷플릭스 실영상 검사를 대신하지 않습니다.

자막 표시의 기반 API: [TextTrack.activeCues](https://developer.mozilla.org/en-US/docs/Web/API/TextTrack/activeCues), [VTTCue.getCueAsHTML](https://developer.mozilla.org/en-US/docs/Web/API/VTTCue/getCueAsHTML). 넷플릭스 DOM 자막 구조는 서비스 변경에 따라 조정이 필요할 수 있습니다.
