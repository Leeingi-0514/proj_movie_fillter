# MovieGuard

브라우저에서 영상별로 등록된 불편한 구간에 블러·음소거·스킵을 적용하는 웹 프로토타입입니다.

## 실행

프로젝트 폴더에서 VS Code의 Live Server를 실행하거나 다음 명령을 사용합니다.

```sh
python3 server.py
```

브라우저에서 http://127.0.0.1:8000/index.html 을 엽니다.

같은 Wi-Fi의 다른 기기에서도 접속하려면 위 명령으로 서버를 실행한 상태에서 터미널의 **같은 Wi-Fi의 다른 기기** 주소를 엽니다. 예를 들어 서버 컴퓨터의 Wi-Fi IP가 `192.168.0.160`이면 `http://192.168.0.160:8000/index.html`로 접속합니다. 다른 기기에서 `localhost`나 `127.0.0.1`을 입력하면 그 기기 자신을 가리키므로 서버에 접속할 수 없습니다.

서버는 기본적으로 모든 IPv4 네트워크 인터페이스에서 접속을 받습니다. 이전 서버가 실행 중이었다면 터미널에서 Ctrl+C로 종료한 뒤 다시 실행합니다. 이 컴퓨터에서만 접속하도록 제한하려면 `python3 server.py --host 127.0.0.1`을 사용합니다. 어떤 폴더에서 실행하더라도 이 프로젝트 폴더의 파일을 제공합니다.

LAN에는 서비스용 HTML·CSS·JavaScript와 영상·포스터·테마 이미지·구간 JSON만 허용 목록에 따라 제공합니다. 서버 실행 파일, 테스트, Git 데이터, 설정 파일과 폴더 목록은 제공하지 않습니다.

연결이 안 되면 두 기기가 같은 Wi-Fi인지 확인하고, macOS 방화벽에서 Python의 수신 연결을 허용합니다. 공유기의 게스트 Wi-Fi나 기기 간 통신 차단 기능이 켜져 있으면 같은 Wi-Fi 이름이어도 접속이 제한될 수 있습니다. 테스트 동안 서버 컴퓨터와 터미널을 켜 두고 잠자기에 들어가지 않게 해 주세요. Wi-Fi가 바뀌면 IP 주소도 달라질 수 있으므로 실행 시 출력되는 주소를 확인합니다.
JSON을 읽기 때문에 HTML 파일을 더블 클릭하는 `file://` 방식 대신 웹 서버를 사용해야 합니다.
이 서버는 영상 탐색에 필요한 바이트 범위 요청을 지원합니다. 기본 `python3 -m http.server` 대신 위 명령이나 Live Server를 사용해 주세요. 다른 포트는 `python3 server.py 8001`처럼 지정할 수 있습니다.

## 이용 방법

1. 홈의 **공포 / 폭력성 / 선정성** 버튼을 선택합니다.
2. 해당 테마의 영상 목록에서 영상을 선택합니다.
3. **블러 / 음소거 / 블러 + 음소거 / 스킵** 중 하나를 선택합니다.
4. 선택한 버튼을 다시 누르면 선택이 해제되고 필터가 꺼집니다. 원하는 버튼을 누르면 해당 방식으로 필터가 다시 켜집니다.
5. **첫 구간 체험하기** 또는 구간 목록을 누르면 해당 구간 2초 전부터 재생합니다.
6. 재생 화면에서 **← / → 방향키**를 누르면 5초씩 뒤로 / 앞으로 이동합니다. 재생 막대에 포커스가 있어도 동일하게 동작하며, 재생·일시정지 상태는 유지됩니다. 영상의 시작과 끝을 넘지 않고, 이동한 위치의 필터도 즉시 반영합니다.

처음 선택되는 방식은 해당 영상의 첫 구간에 기록된 `type`입니다. 버튼으로 선택한 방식은 그 영상의 모든 등록 구간에 적용됩니다. 구간이 없는 영상은 필터를 끈 상태로 재생합니다.

스킵할 구간에 들어오면 영상을 잠시 멈추고 검은 화면에 해당 구간의 `summary`를 약 3초간 표시한 뒤 구간 끝으로 이동합니다. 원래 재생 중이었다면 이어서 재생하고, 일시정지 상태였다면 멈춘 상태를 유지합니다. 겹치거나 맞닿은 구간은 하나로 묶어 요약을 중복 없이 함께 표시합니다. 요약을 보여주는 중에도 재생 버튼으로 이후 재생 여부를 바꿀 수 있으며, 필터를 끄거나 다른 위치로 이동하면 요약 표시를 해제합니다.

자동 음소거는 구간이 끝나거나 필터를 끄면 해제됩니다. 구간 안에서 사용자가 **소리 켜기**를 누르면 그 구간에서는 다시 자동 음소거하지 않습니다. 다음 구간에서는 필터가 다시 적용됩니다. 사용자가 미리 직접 음소거한 경우에는 그 설정을 유지합니다.

재생 화면은 영상의 표시 영역 비율에 맞춰 크기를 정하고, 전체 화면에서는 그 영역을 화면에 꽉 차게 확대합니다. 비율이 다른 전체 화면에서는 가장자리 일부가 잘릴 수 있습니다. 원본 파일을 자르거나 재인코딩하지 않으며 필터 시간도 그대로 유지합니다.

영상 파일 안에 검은 녹화 여백이 들어 있으면 `videos.json`의 해당 항목에 `contentFrame`을 설정합니다. `x`, `y`, `width`, `height`는 원본 영상 픽셀 기준의 실제 영상 영역입니다. 예를 들어 1080×1920 세로 녹화 안의 영상이 `(0, 734)`에서 시작하고 1080×452 크기라면 `"contentFrame": { "x": 0, "y": 734, "width": 1080, "height": 452 }`로 지정합니다. 여백이 없는 영상에는 생략합니다. 영상 파일을 교체하면 이 좌표도 확인해 주세요.

체험용 영상과 실제 등록 영상은 `assets/videos.json`에서 관리합니다. 영상마다 연결된 구간 파일로 필터 동작을 확인할 수 있습니다.

## 테마별 영상 폴더

현재 서비스에는 MP4 영상만 등록합니다. 공포는 `assets/horror/`, 폭력성은 `assets/violence/`, 선정성은 `assets/sexual/`에 넣습니다. 구간 JSON은 `assets/segments/`에 영상과 같은 이름으로 저장합니다. 예를 들어 `assets/horror/the-priests.mp4`는 `assets/segments/the-priests.json`과 연결합니다. 파일명의 대소문자도 일치해야 합니다.

현재 등록된 영상은 공포 3개(the-priests, gonjiam, quiet-place), 폭력성 2개(dp, teach-you), 선정성 2개(bridgerton, parasite)입니다. 이전 데모 항목은 영상 목록에서 제외했습니다.

목록은 `assets/videos.json`으로 관리하므로 새 파일을 넣은 뒤에는 해당 목록에도 등록해야 합니다. 온라인 배포 시에는 테마 폴더, 구간 JSON, 수정된 `videos.json`을 함께 업로드합니다.

## 새 영상 등록

1. MP4 영상 파일을 `assets/horror/`, `assets/violence/`, `assets/sexual/` 중 해당 테마 폴더에 넣습니다.
2. `assets/sample-segments.json`과 같은 형식의 파일을 `assets/segments/`에 영상과 같은 이름으로 만듭니다.
3. `assets/videos.json`의 `videos` 배열에 아래와 같은 항목을 추가합니다.

영상 카드에 사용할 포스터는 `assets/posters/`에 넣고 각 영상의 `poster`에 정확한 파일 경로를 등록합니다. 파일명에 공백이 있거나 영상과 이름이 달라도 직접 연결할 수 있습니다. 목록의 이미지는 세로 2:3 영역을 여백 없이 채우며, 원본 비율이 다르면 가장자리 일부가 잘릴 수 있습니다.

```json
{
  "id": "my-horror-video",
  "theme": "horror",
  "title": "새 영상 제목",
  "description": "영상에 대한 소개",
  "src": "assets/horror/my-horror-video.mp4",
  "segments": "assets/segments/my-horror-video.json",
  "poster": "assets/posters/my-horror-video_poster.jpeg",
  "demo": false
}
```

- `id`: 중복되지 않는 영상 ID
- `theme`: `horror`(공포), `violence`(폭력성), `sexual`(선정성)
- `src`, `segments`: 프로젝트 루트 기준 경로
- `poster`: 영상 목록 카드에 표시할 포스터 이미지 경로
- `demo`: 체험용 영상이면 `true`로 지정합니다. 영상 목록의 ‘필터 체험용’ 배지와 목록·재생 화면의 체험용 안내문을 표시하는 용도입니다. 실제 영상은 `false`로 지정하거나 생략합니다. 필터 구간의 적용 여부에는 영향을 주지 않습니다.
- 지원 형식은 브라우저마다 다르며, H.264/AAC MP4를 권장합니다.
- 등록된 영상이 없는 테마에는 준비 중 안내를 표시합니다.
- 현재는 정적 파일로 영상을 등록하는 구조이며, 웹에서 파일을 업로드하거나 서버에 저장하는 기능은 포함하지 않습니다.

구간 파일 예시:

```json
{
  "title": "새 영상 제목",
  "segments": [
    {
      "id": "scene-001",
      "start": 16,
      "end": 22,
      "type": "both",
      "reason": "갑작스러운 놀람이 있는 구간",
      "summary": "인물 앞에 예상하지 못한 대상이 나타납니다."
    }
  ]
}
```

`reason`은 필터를 지정한 이유, `summary`는 스킵할 때 보여줄 짧은 장면 요약입니다. 요약은 문자열로 입력하며, 줄바꿈도 표시됩니다. 이전 JSON에 `summary`가 없거나 빈 문자열이면 기본 이동 안내를 표시합니다. 기존 구간의 요약은 등록된 설명을 바탕으로 작성했으므로, 실제 장면을 확인하며 필요에 맞게 수정해 주세요.

시간 단위는 초이며, 시작 시점은 포함하고 종료 시점은 포함하지 않습니다. `type`은 `blur`, `mute`, `both`, `skip` 중 하나입니다. 구간이 없다면 `"segments": []`로 저장합니다. 구간 ID는 같은 파일 안에서 중복되지 않아야 하며, 종료 시간은 시작 시간보다 커야 합니다. 영상 길이 안의 시간을 입력해 주세요.

웹 재생 화면에서는 시작 시간이 가장 빠른 구간의 `type`을 기본 선택 필터로 사용합니다. 이후 사용자가 버튼을 선택하면 그 방식이 모든 등록 구간에 적용됩니다. 구간마다 다른 필터를 자동 적용하는 방식은 아닙니다. 기존 Chrome 확장 프로그램에서는 각 구간의 `type`을 실제 적용 필터로 사용하므로 구간 파일의 `type`을 유지합니다.

웹서비스용 `videos.json`과 구간 JSON에는 `version`이 필요하지 않습니다. 현재 여러 데이터 버전을 구분하거나 변환하는 기능이 없으며, 배열·ID·시간·필터 종류를 직접 검증합니다. 구간의 `category`도 웹에서는 사용하지 않아 제거했습니다. 테마 분류는 `videos.json`의 `theme`으로 관리합니다. 기존 파일에 `version`이나 `category`가 남아 있어도 웹에서 읽을 수 있습니다.

## 파일 구성

- `index.html`, `style.css`, `script.js`: 테마 선택 홈
- `videos.html`, `videos_script.js`: 테마별 영상 목록과 빈 목록·오류 안내
- `catalog.js`, `assets/videos.json`: 테마 정의와 영상 목록
- `player.html`, `player_style.css`, `player_script.js`: 재생 화면과 필터 선택
- `video-layout.js`: 실제 영상 영역과 플레이어 크기에 맞춘 비율 유지·화면 채움 계산
- `server.py`: 영상 앞뒤 이동을 지원하는 로컬 실행 서버
- `assets/horror/`, `assets/violence/`, `assets/sexual/`: 테마별 MP4 영상
- `filter-engine.js`: 구간 검증, 겹친 구간 스킵·요약 묶기, 사용자 음소거 설정 처리
- `extension/skip-summary.js`: 웹·확장 프로그램이 함께 사용하는 3초 요약·일시정지·구간 이동 처리
- `assets/segments/`: 영상별 필터 구간 JSON
- `extension/`: 넷플릭스용 Chrome 확장 프로그램 (작품별 구간·시간 보정·블러·음소거·스킵)

## 검증

Node.js가 설치된 환경에서 의존성 설치 없이 실행합니다.

```sh
npm test
python3 -B -m unittest discover -s tests -p 'test_server.py'
python3 -B -m unittest discover -s tests -p 'test_prepare_videos.py'
```

비동기 음소거 이벤트, 구간 종료 시 해제, 구간 안에서 직접 음소거 해제, 사용자 설정 유지, 구간 경계, 겹친 구간 스킵, 영상별 JSON 연결을 검사합니다.

## Chrome 확장 프로그램

넷플릭스용 확장 프로그램을 `extension/`에 구현했습니다. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `extension` 폴더를 선택한 다음, 넷플릭스 탭을 새로고침합니다.

본편을 재생하고 확장 팝업에서 기존 클립 구간 또는 JSON을 불러온 뒤 시간 보정을 맞춰 **현재 작품에 저장·적용**을 누릅니다. 저장한 구간은 넷플릭스 작품·회차 ID별로 적용됩니다. 기존 클립 시간은 넷플릭스 본편 시간과 다르므로 시간 보정이 필요합니다.

자세한 설치·사용법과 실제 넷플릭스 검증 범위는 [extension/README.md](extension/README.md)를 참고해 주세요. 로컬 HTML5 영상 통합 검사는 `python3 tests/serve_extension_qa.py`로 실행합니다. 민감 장면 자동 분석은 포함하지 않습니다.
